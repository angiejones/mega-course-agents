# MEGA course agents

Build a retail customer service agent with TypeScript and Mastra.

## Open in GitHub Codespaces

Select **Code**, then **Codespaces**, then **Create codespace on main**. The development container includes Node.js 22, npm, Git, and the SQLite command-line tool.

You can also create a Codespace from an authenticated GitHub CLI:

```bash
gh codespace create --repo angiejones/mega-course-agents --branch main
```

The setup check prints the installed tool versions. Port 4111 is configured for Mastra Studio once the application is added. Keep forwarded ports private.

Keep API keys in Codespaces secrets or a local environment file. Environment files and local database files are excluded from Git.
